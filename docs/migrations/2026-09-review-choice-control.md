# レビュー選択と指定の改訂

実装を一区切りしたときの 3 択を「別ベンダーでレビュー」「同ベンダーでレビュー」「レビューしない」に短縮しました。
開発者がレビュアーを指定できるようにし、自走中は 3 択で止まらず、指定または推奨の経路を実行するようにしました。
CLI を起動できない環境を「リモートコントロール環境」と呼んでいた箇所を「クラウド実行環境など」に改めました。Claude Code の Remote Control はローカルの機械で動き、CLI を起動できるためです。

## 取り込み先で必要な作業
- CLAUDE.md / AGENTS.md の相互レビュー要約にある 3 択の文言を「別ベンダーでレビュー」「同ベンダーでレビュー」「レビューしない」へ、「リモートコントロール環境」を「クラウド実行環境など」へ書き換える。レビュアーの指定と自走中の扱いを要約に足すかは任意（正本は SKILL と docs/cross-review.md）。

vendored ファイル（`.claude/skills/cross-review/SKILL.md`、`docs/cross-review.md`、`tools/cross-review.js`）は同期で更新されるので、取り込み先での手作業は不要です。
