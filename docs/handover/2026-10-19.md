## 落とし穴

- 委譲した Codex の実装担当は、#157 の役割文が配られるまで、リポジトリの規約に従ってクロスレビューを始めることがある(ktysne/claude-codex-bridge#157)。依頼文に「クロスレビューを実行しない」と書く。
- bridge の定義と `codex-agent.sh` は `~/.claude` へ配って初めて効く。配布はマージの後に行う。
- ai-cross-review の変更は、bridge を含む取り込み先へ一括同期(`npm run sync:all`)して初めて効く。同期はスタックをすべてマージした後に行う。
- `npm run review:codex` で、Codex が最終報告を書いた後も `codex-agent.sh` が終了せず、cross-review が待ち続けることがある(2026-10-19 に 1 回観測、未起票)。Codex のログに `tokens used` が出てから 2 分たっても終わらなければ、ラッパーを止めて同じレビューを回し直す。止めた実行は往復に数えられない。
